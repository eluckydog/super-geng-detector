🏗️ 双引擎架构

🔬 理工科引擎（7 维）

针对数值/图像类论文。检测数据分布异常、粒度冲突、SD 共谋、选择性报告、列差值恒定、图像复用、图像拼接。

Benford 全位联合 扩展 GRIM 检验 SD 贝叶斯一致性 p-curve PRNU 传感器指纹 JPEG 双重压缩 Copy-Move 检测

📖 文科引擎（5 维）

针对文本/论证类论文。检测风格突变、因果谬误、引用虚设、论证空转、AI 生成文本。

HMM 文本风格溯源 因果图方法论校验 引用-正文一致性 论证结构分析 AI 生成文本识别

🚀 快速使用

# 自动分类论文类型并检测
python scripts/super_geng.py detect paper.pdf --auto
# 数值法医（从 CSV 中检测异常）
python scripts/super_geng.py stats data.csv
# 图像法医（检测图像复用/拼接）
python scripts/super_geng.py image figure.png
